
Plaizer IA 🚀
Un asistente virtual inteligente para la gestión de tareas con integración de chatbot.

📌 Descripción
Plaizer IA es una aplicación web diseñada para optimizar la gestión de tareas mediante un chatbot impulsado por inteligencia artificial. Incluye soporte para integración de calendarios con CalDAV, lo que permite a los usuarios sincronizar sus eventos en múltiples dispositivos.

🛠 Tecnologías Utilizadas

Front-End
React con Vite ⚡
React Router v7 (para la gestión de rutas)
Tailwind CSS (para el diseño de interfaz)
Context API o Redux (para la gestión de estado)
Back-End
Node.js con Express.js
PostgreSQL con Sequelize (ORM)
OpenAI API / Dialogflow (para el chatbot)
Autenticación con JWT
Herramientas Adicionales
Git y GitHub (para control de versiones)
VS Code (con ESLint y Prettier para estandarización de código)
Vercel o Railway (para despliegue)
